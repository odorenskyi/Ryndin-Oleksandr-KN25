# Лабораторна робота № 9

**Тема:** Модульне програмування та тестування програмного забезпечення мовою C++

**Мета:** Опанувати принципи розділення коду на модулі, навчитися створювати власні бібліотеки та покривати їх автоматизованими тестами за допомогою тест-драйвера.

**Завдання:** Реалізувати функцію згідно з варіантом, оформити її у вигляді модуля (бібліотеки) та покрити автоматизованими тестами через окремий тест-драйвер.

**Варіант № 2**

\---

## Структура проєкту

```

lab09/

&#x20; README.md

&#x20; prj/    — проєкти Code::Blocks

&#x20;   Software/                

&#x20;     LibModulesRyndin/

&#x20;          modules\_ryndin.cpp

&#x20;          Modules.h

&#x20;     RyndinTask/

&#x20;          Ryndin\_task.cpp

&#x20;     TestDriver/ 

&#x20;          TestDriver.cpp

&#x20;   lab09.cbp

&#x20;   lab09.depend

&#x20;   lab09.layout

&#x20;   test lab 09/        — проєкт тест-драйвера

&#x20;   bin/                — скомпільовані бінарники

```

## Запуск

**Основна програма:**

```
Software\\Ryndin\_task.exe
```

**Тест-драйвер** (запускати лише через командний рядок):

```
Software\\TestDriver.exe
```

> ⚠️ Подвійний клік на `TestDriver.exe` одразу закриє консоль — це нормально.  
> Щоб побачити результати, відкрий cmd і запусти: `TestDriver.exe \& pause`

**Результати тестів:** `TestSuite\\test\_results.txt`
