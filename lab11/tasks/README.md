\# Лабораторна робота №11 — Довідник кодів мобільних операторів України



\## Опис



Консольна програма на C++ для роботи з довідником кодів мобільних операторів України.  

Реалізована з розподілом на модулі відповідно до методології командної розробки.



\## Функціонал



\- Завантаження довідника з файлу при запуску

\- Пошук запису за кодом або назвою оператора

\- Виведення всього довідника на екран

\- Додавання нового запису

\- Вилучення запису за кодом

\- Експорт довідника у текстовий файл

\- Автоматичне збереження при виході
